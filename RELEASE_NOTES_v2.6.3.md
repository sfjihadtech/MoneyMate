# MoneyMate v2.6.3

- Professional PDF export: separate Income and Expenses pages, category summaries, final totals, MoneyMate-branded color identity, pagination and statement metadata.
- Professional CSV export: separate Income and Expense table sections, category totals and final summary while retaining import-safe transaction rows.
- Redesigned Export Data screen with format cards, date range, statement preview and totals.
- Transaction swipe actions: right reveals Edit, left reveals Delete with confirmation; paired transfer records remain protected.
- Account swipe actions: right reveals Edit, left reveals Delete with confirmation.
- Removed the Home top-right profile button. The left profile/avatar beside the user's name now opens Profile & Settings and displays the user's uploaded photo when available.
- Bottom navigation and FAB now use the five user-supplied icon assets.
- Registration full-name placeholder changed to “Enter your full name”.
- Version bumped to 2.6.3 (versionCode 6).
